EmbrSAM2 使い方（Linux）
========================

■ インストール
1. ZIP を展開
2. 管理者権限で実行（必須）
     cd EmbrSAM2-linux-x86_64-*
     ./install.sh
   ※ /usr/OFX/Plugins と /opt/Embr へ書くため sudo が必要です
3. Flame / Resolve を再起動

■ 正しい配置場所（重要）

OFX プラグイン（ホストが探す標準パス）:
  /usr/OFX/Plugins/EmbrSAM2.ofx.bundle

  ※ Linux の OFX 公式標準は /usr/OFX/Plugins です。
    ~/OFX/Plugins では Flame / Resolve に出ません。
  ※ Flame は /usr/OFX/Plugins にプラグインが無いと
    OpenFX ノード自体が出ないことがあります。

アプリデータ（モデルなど）:
  /opt/Embr/EmbrSAM2/
    models/sam2/image_encoder.onnx
    models/sam2/image_decoder.onnx
    env.sh
    使い方.txt
    bin/uninstall.sh

■ ホストでの使い方
1. Batch の OpenFX、または OFX エフェクト一覧
2. 「Embr」→「EmbrSAM2」
3. Box / Point で対象を指定

デフォルトのモデルパス（通常変更不要）:
  /opt/Embr/EmbrSAM2/models/sam2/image_encoder.onnx
  /opt/Embr/EmbrSAM2/models/sam2/image_decoder.onnx

■ 一覧に出ないとき
1. 次があるか確認
     ls -la /usr/OFX/Plugins/EmbrSAM2.ofx.bundle/Contents/Linux-x86-64/
2. ホストを完全終了して再起動
3. Flame の場合、OpenFX ノードを Batch に出して
   Load Plugin ドロップダウンを確認
4. クラッシュする場合は ignore リストを確認
     /opt/Autodesk/presets/<version>/status/cf_ofx_ignore_list.cfg
5. 旧インストールを消す
     rm -rf ~/OFX/Plugins/EmbrSAM2.ofx.bundle

独自パスに入れたい場合のみ:
  sudo OFX_PLUGIN_DIR=/どこか/OFX/Plugins EMBR_SAM2_HOME=/opt/Embr/EmbrSAM2 ./install.sh
  かつホスト起動前に:
  export OFX_PLUGIN_PATH=/どこか/OFX/Plugins

■ アンインストール
  sudo /opt/Embr/EmbrSAM2/bin/uninstall.sh
または展開フォルダで
  ./uninstall.sh
