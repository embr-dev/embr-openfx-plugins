```bash
./scripts/download_matanyone2_weights.sh
```

Places `matanyone2.pth` here. The OFX plugin currently uses a demo soft-matte;
neural inference inside OFX is planned next. Use `scripts/run_matanyone2_offline.py`
for the official PyTorch pipeline today.
